# VIP (Veze i poznanstva)

Permanent identifiers for VIP, a civic dataset of connections between people and
organisations, built for journalistic investigation, and for its
vocabulary additions to PoderVocab.

- `https://w3id.org/vip/vocab#` — the vocabulary (OWL/RDFS terms, Turtle)
- `https://w3id.org/vip/rs/` — instance data for Serbia; other countries get
  their own two-letter segment under `https://w3id.org/vip/`
